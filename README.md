# Arete Pro

Learning outcomes assessment in the Taejae Learning Suite (Paideia): course, program and institution results from confirmed rubric ratings.

This version is the design mockup turned into a working page with sample data. Sign-in and the shared Supabase data are not connected yet.

## Build

`index.html` is generated. Edit the pages in `src/pages/` (one file per screen) or the shell in `src/shell.html`, then run:

```
python -I src/build_app.py src/pages .
```
